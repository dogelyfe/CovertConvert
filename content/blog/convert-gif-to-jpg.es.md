GIF es uno de los formatos de imagen más antiguos aún en uso común. Es famoso por las animaciones, pero a veces terminas con un GIF que es solo una imagen estática normal. Y los GIF estáticos tienen algunos problemas reales.

## Por qué GIF es malo para fotos

GIF fue diseñado en 1987 para gráficos simples. Tiene algunas limitaciones serias:

**256 colores máximo.** Eso es todo. Las fotos tienen millones de colores. Cuando guardas una foto como GIF, se aplasta a 256 colores y se ve terrible—bandas, difuminado, artefactos extraños.

**Tamaños de archivo grandes para fotos.** La compresión de GIF funciona bien para gráficos simples pero mal para fotografías. Una foto GIF es a menudo más grande que el JPG equivalente mientras se ve peor.

**Sin transparencia parcial.** GIF tiene transparencia, pero es todo o nada para cada píxel. Sin bordes suaves.

## Cuándo tendrías un GIF estático

**Gráficos web viejos.** GIF era el estándar para imágenes web antes de que JPG y PNG tomaran el control. Sitios web viejos, contenido archivado y gráficos heredados suelen ser GIF.

**Capturas de pantalla de software antiguo.** Algunas herramientas viejas exportaban a GIF por defecto.

**Guardado accidental como GIF.** Pasa. Alguien seleccionó el formato equivocado en su editor de imágenes.

**Fotograma extraído de GIF animado.** Querías un fotograma de una animación y ahora tienes un GIF.

## Cuándo convertir GIF a JPG

Si tienes un GIF estático que en realidad es una fotografía o contenido fotográfico, [convertir a JPG](/gif-to-jpg/):

- Usualmente reduce el tamaño del archivo significativamente
- Preserva los colores mejor (millones vs 256)
- Lo hace compatible con más cosas

Básicamente, si el GIF no está animado y no necesita transparencia, JPG es casi siempre mejor.

## Cuándo quedarse con GIF

**Está animado.** Obviamente no conviertas una animación a JPG estático.

**Son gráficos simples con colores sólidos.** Logos, iconos, diagramas con colores planos—GIF o PNG está bien.

**Necesitas esa transparencia específica.** La transparencia binaria de GIF funciona para algunos casos de uso.

## ¿Y PNG?

Para imágenes estáticas que necesitan transparencia o son gráficos simples, PNG es casi siempre mejor que GIF. Mejor compresión, más colores, transparencia alfa adecuada.

La única razón por la que GIF persiste para imágenes no animadas es el contenido heredado. Nadie elige GIF para nuevas imágenes estáticas en 2025.

## Convirtiendo

Si tienes un GIF que debería ser un JPG, la [conversión es rápida](/gif-to-jpg/). El resultado probablemente se verá mejor y será más pequeño. Si es una foto que se guardó incorrectamente como GIF, podrías notar una mejora de calidad solo por tener acceso a la profundidad de color completa de nuevo.
